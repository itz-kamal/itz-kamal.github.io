Featured · MSc Dissertation Open source

Risk-Based Vulnerability Prioritisation Tool

Tells security teams which vulnerabilities to fix first. Feed in a list of CVEs and the pipeline enriches each one with severity (CVSS), exploit probability (EPSS) and confirmed-exploitation status (CISA KEV), then returns a ranked remediation queue with a patch-by deadline for every CVE — immediate for KEV, then 7, 30, 90 or 180 days.

Three-stage pipeline (data collection → statistical analysis → priority ranking) with rate-limited, batched calls to the NVD and EPSS APIs, data-quality checks and fully reproducible command-line runs.
